# My Security & Network Toolkit 🛡️

A collection of useful security and networking tools automated for quick deployment in cloud environments (like Google Cloud Shell, GitHub Codespaces, or fresh Linux instances).

## Quick Setup / Clone & Install

Run the following command in your terminal to clone the repo and install all tools instantly:

\`\`\`bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git && cd YOUR_REPO_NAME && chmod +x install.sh && ./install.sh
\`\`\`

## Included Tools
- **Nmap**: Network exploration and port scanning.
- **Gobuster**: Directory/file & DNS busting tool.
- **Tshark**: Network packet analyzer (CLI version of Wireshark).
- **Dig / Whois**: DNS lookup and domain information utilities.
- **Curl / Wget**: HTTP request and file downloading tools.
